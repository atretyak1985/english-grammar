<Section id="cheat" n={17} title="Шпаргалка">

<Lede>Уся тема на одній картці. Зробіть скріншот — і звіряйтесь, поки ручка реальності не стане рефлексом.</Lede>

<Cheat title="Умовні речення — все найважливіше">
  <CheatRow label="Ручка реальності">
    реально → теперішній час · уявно → крок назад (Past Simple) · не сталося → два кроки (Past Perfect) · у if-частині НІКОЛИ немає will/would
  </CheatRow>
  <CheatRow label="Zero — закон">
    <CheatCode>If you press F5, the page reloads.</CheatCode> · правило/звичка, спрацьовує щоразу · if ≈ when
  </CheatRow>
  <CheatRow label="First — план">
    <CheatCode>If the tests pass, we will deploy.</CheatCode> · реальний випадок у майбутньому · замість will можна can/might/наказ
  </CheatRow>
  <CheatRow label="Second — мрія">
    <CheatCode>If I had more time, I would learn Polish.</CheatCode> · уявне сьогодні/завтра · be → <CheatCode>were</CheatCode> для всіх: <CheatCode>If I were you…</CheatCode>
  </CheatRow>
  <CheatRow label="Third — жаль">
    <CheatCode>If we had tested it, we would have caught the bug.</CheatCode> · минуле, якого не було · обидві форми довгі: had + V3 і would have + V3
  </CheatRow>
  <CheatRow label="Змішані">
    причина тоді → наслідок зараз: <CheatCode>…had saved…, …wouldn't be rewriting it now</CheatCode> · риса зараз → подія тоді: <CheatCode>…were faster, …would have rolled back</CheatCode> · маркер: now
  </CheatRow>
  <CheatRow label="Родичі if">
    <CheatCode>unless</CheatCode> = якщо не (без другого not!) · <CheatCode>in case</CheatCode> = страховка наперед · <CheatCode>as long as / provided</CheatCode> = за умови, що · після всіх — без will
  </CheatRow>
  <CheatRow label="I wish">
    про зараз → <CheatCode>wish + Past Simple</CheatCode> · про минуле → <CheatCode>wish + Past Perfect</CheatCode> · чужі звички → <CheatCode>wish + would</CheatCode> (про себе — не можна)
  </CheatRow>
  <CheatRow label="Кома">
    if-частина першою → кома є: <CheatCode>If it rains, we stay.</CheatCode> · другою → коми немає: <CheatCode>We stay if it rains.</CheatCode>
  </CheatRow>
</Cheat>

<Note variant="tip" title="Одне речення замість усієї картки">
  Якщо запамʼятати з теми лише одне: <b>що менше ви вірите в умову, то далі в минуле відступає час</b> — а will/would завжди лишаються в результаті. Кожного разу, коли рука пише if + will, спитайте себе, що ви насправді прогнозуєте — і перенесіть прогноз у друге плече.
</Note>
