### 2.1 Форма — повна таблиця

<Formula
  lines={[
    { sign: '+', body: <>I / you / we / they <K>+ V1</K></>, comment: 'I work, they deploy — початкова форма' },
    { sign: '+', body: <>he / she / it <K>+ V-s</K></>, comment: 'he works, she deploys — єдина зміна в усій парадигмі' },
    { sign: '−', body: <>I / you / we / they <Neg>+ do not (don&apos;t) + V1</Neg></>, comment: "I don't work — без -s!" },
    { sign: '−', body: <>he / she / it <Neg>+ does not (doesn&apos;t) + V1</Neg></>, comment: "he doesn't work — НЕ «doesn't works»" },
    { sign: '?', body: <><Q>Do</Q> + I / you / we / they <Q>+ V1</Q> … ?</>, comment: 'Do you deploy on Fridays?' },
    { sign: '?', body: <><Q>Does</Q> + he / she / it <Q>+ V1</Q> … ?</>, comment: 'Does it scale? — НЕ «Does it scales?»' },
    { sign: '?', body: <>Wh- + <Q>do / does</Q> + підмет <Q>+ V1</Q> … ?</>, comment: 'How long does the deploy take?' },
  ]}
  note="Короткі відповіді: Yes, I do. / No, he doesn't."
/>

<Note variant="warn" title="Правило, яке порушують усі — «-s позначається один раз»">
  Це те саме правило, що й <code>did + V1</code> у минулих часах, тільки для теперішнього. Щойно ви сказали <code>does</code> — воно забрало <i>-s</i> собі, і основному дієслову вже нічого не залишається.

  <GoodBad>
    <Bad>She doesn&apos;t <b>knows</b> about the outage.<br />Does it <b>scales</b> to a million users?<br />Why does he <b>pushes</b> to main?</Bad>
    <Good>She doesn&apos;t <b>know</b> about the outage.<br />Does it <b>scale</b> to a million users?<br />Why does he <b>push</b> to main?</Good>
  </GoodBad>
</Note>

#### Дієслово to be — окремий випадок, без do

|  | Стверджувальне | Заперечне | Питальне |
|---|---|---|---|
| **I** | I **am** on call. | I **am not** (**I'm not**) on call. | **Am** I on call? |
| **he / she / it** | She **is** the reviewer. | She **isn't** the reviewer. | **Is** she the reviewer? |
| **you / we / they** | They **are** blocked. | They **aren't** blocked. | **Are** they blocked? |

<Muted><b>Чому так?</b> <i>Am / is / are</i> — самі по собі допоміжні дієслова. Їм не потрібен «помічник» <i>do</i>: вони вміють утворювати заперечення й питання самостійно.</Muted>

<GoodBad>
  <Bad>I <b>don&apos;t am</b> on call this week.<br /><b>Does</b> she <b>is</b> the reviewer?</Bad>
  <Good>I <b>am not</b> on call this week.<br /><b>Is</b> she the reviewer?</Good>
</GoodBad>

#### Дієслово have — коли потрібне does, а коли ні

<Muted>На відміну від <i>be</i>, дієслово <i>have</i> у сучасній англійській звичайне: питання й заперечення воно будує через <i>do / does</i>.</Muted>

<ExList>
  <Ex ua="Скільки у тебе підлеглих?" why={<>Стандартний варіант. <i>How many direct reports have you?</i> — архаїчно.</>}>How many direct reports <M t="ps">do</M> you <M t="ps">have</M>?</Ex>
  <Ex ua="У неї немає доступу до продакшну." why={<>✗ <i>She hasn&apos;t access</i> — так уже не кажуть.</>}>She <M t="ps">doesn't have</M> production access.</Ex>
  <Ex ua="У вас є тестове середовище?" why={<><i>have got</i> — розмовний британський варіант, теж правильний: <i>Have you got a staging environment?</i></>}><M t="ps">Do</M> you <M t="ps">have</M> a staging environment?</Ex>
</ExList>

<ExList>

  <Ex ua="Як часто ви перевіряєте бекапи?">How often <M t="ps">do</M> you <M t="ps">test</M> the backups?</Ex>

<Note title="Місце прислівника частоти">
  <b>Перед</b> звичайним дієсловом: <i>I <b>usually</b> work from home.</i><br />
  <b>Після</b> <i>be</i>: <i>She <b>is</b> <b>always</b> late.</i><br />
  <b>Між</b> допоміжним і смисловим: <i>I <b>don't usually</b> take calls after seven.</i><br />
  Прислівники з чіткою частотою можна виносити в кінець: <i>We deploy on Fridays <b>every week</b>.</i>
</Note>

### 2.3 Правопис -s у третій особі

| Правило | Приклади |
|---|---|
| За замовчуванням — додаємо **-s** | work → work**s** · deploy → deploy**s** · scale → scale**s** |
| Після **-s, -ss, -sh, -ch, -x, -z** → **-es** | miss → miss**es** · push → push**es** · watch → watch**es** · fix → fix**es** |
| Після **-o** → **-es** | go → go**es** · do → do**es** |
| Приголосна + **-y** → **-ies** | try → tr**ies** · deny → den**ies** · apply → appl**ies** |
| Голосна + **-y** → просто **-s** | play → play**s** · deploy → deploy**s** · buy → buy**s** |
| Три неправильні форми | be → **is** · have → **has** · do → **does** |

<Note title="🔊 Вимова -s — три звуки, а не один">
  Українці за звичкою вимовляють <i>/s/</i> скрізь. Приблизно в половині випадків це помилка — і вона одразу чутна.

  | Звук | Після чого | Приклади |
  |---|---|---|
  | **/s/** | глухих приголосних: p, t, k, f, θ | ship**s** /ʃɪps/ · works /wɜːks/ · get**s** /ɡets/ · help**s** /helps/ |
  | **/z/** | дзвінких приголосних і голосних | run**s** /rʌnz/ · scale**s** /skeɪlz/ · deploy**s** /dɪˈplɔɪz/ · know**s** /nəʊz/ |
  | **/ɪz/** | **тільки** після s, z, ʃ, ʒ, tʃ, dʒ | push**es** /ˈpʊʃɪz/ · miss**es** /ˈmɪsɪz/ · watch**es** /ˈwɒtʃɪz/ · manage**s** /ˈmænɪdʒɪz/ |

  Окремо запамʼятайте два слова, які вимовляються не так, як пишуться: <b>does</b> /dʌz/ (не /duːz/) і <b>says</b> /sez/ (не /seɪz/).
</Note>

<History title="чому -s лишилося тільки в третій особі">
  У давньоанглійській дієслово мало повний набір закінчень для кожної особи, як зараз в українській: <i>ic lufie</i>, <i>þū lufast</i>, <i>hē lufaþ</i>. Далі більшість закінчень стерлася — і вижило одне-єдине, у третій особі однини.

  Причому вижило не те, яке було в літературній нормі. Південне <i>-eth</i> (<i>he loveth</i>, <i>he hath</i>) поступилося північному <i>-es</i>, і в текстах Шекспіра ще видно обидва варіанти паралельно. Детальніше — у розділі 15.
</History>
