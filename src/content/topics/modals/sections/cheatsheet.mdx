<Cheat title="МОДАЛЬНІ — ШВИДКА ДОВІДКА">
  <CheatRow label="ТРИ ЗАЛІЗНІ ПРАВИЛА">
    Гола основа: <CheatCode>he can swim</CheatCode> — без to, без -s · заперечення без do: <CheatCode>can’t, mustn’t</CheatCode> · питання інверсією: <CheatCode>Can you…?</CheatCode><br />
    Винятки-протези (звичайні дієслова): have to · need to · be able to · ought to
  </CheatRow>
  <CheatRow label="ДВА ПОВЕРХИ">
    Поверх 1 — правила світу: можна, варто, мусиш. Поверх 2 — оцінка шансів: мабуть, можливо, точно ні.<br />
    <i>You must wear a badge</i> (тиск) ↔ <i>You must be tired</i> (здогад). Поверх вибирає контекст.
  </CheatRow>
  <CheatRow label="УМІННЯ">
    зараз — <b>can</b> · загальне в минулому — <b>could</b> · «вдалося один раз» — <b>was able to / managed to</b> (НЕ could!)<br />
    майбутнє — <b>will be able to</b> · після to — <b>to be able to</b>
  </CheatRow>
  <CheatRow label="ПРОХАННЯ — ДРАБИНА ВВІЧЛИВОСТІ">
    собі: Can I → Could I → May I · співрозмовнику: Can you → Could you → Would you mind + -ing<br />
    Минула форма = дистанція = ввічливість. У листах за замовчуванням: <CheatCode>Could you…?</CheatCode>
  </CheatRow>
  <CheatRow label="ТИСК — ВІД ПОРАДИ ДО ЗАБОРОНИ">
    should (варто) → ’d better (краще б, бо інакше…) → have to (мусиш: обставини) → must (мусиш: я наполягаю / писане правило) → mustn’t, can’t (не можна)
  </CheatRow>
  <CheatRow label="ГОЛОВНА ПАСТКА">
    <b>mustn’t = заборона</b> («не смій») · <b>don’t have to = свобода</b> («не обовʼязково»)<br />
    ✗ You mustn’t come — це «тобі заборонено прийти», а не «можеш не приходити»!
  </CheatRow>
  <CheatRow label="ШКАЛА ВПЕВНЕНОСТІ">
    must be (~95%, мабуть, точно) → should be (~75%, за ідеєю) → may / might / could be (30–50%, можливо) → can’t be (~0%, точно ні)<br />
    Протилежність must be — can’t be, НЕ mustn’t be. «Можливо, ні» — might not.
  </CheatRow>
  <CheatRow label="МИНУЛЕ, ЯКОГО НЕ БУЛО: MODAL + HAVE + V3">
    should have done — слід було (докір) · shouldn’t have — дарма · could have — міг би (не сталося)<br />
    must have — мабуть, так і було · might have — можливо, було · can’t have — не могло бути<br />
    Пишеться завжди <CheatCode>have</CheatCode>: ✗ should of, ✓ should have / should’ve
  </CheatRow>
  <CheatRow label="ПРОТЕЗИ ДЛЯ ВІДСУТНІХ ФОРМ">
    ✗ musted → had to · ✗ will must → will have to · ✗ will can → will be able to · ✗ to can → to be able to<br />
    Протези — звичайні дієслова: he has to, Do I have to…?, she needs to
  </CheatRow>
  <CheatRow label="ВОЛЯ: WILL / WOULD">
    I’ll do it — рішення-обіцянка · won’t — відмова (людей і речей: the door won’t open)<br />
    would — воля в минулому (wouldn’t start), ввічливість (I’d like), звичка (grandpa would bake)<br />
    Shall we…? — «нумо?» · Shall I…? — «хочеш, я…?»
  </CheatRow>
  <CheatRow label="ПЕРЕВІРКИ-ПІДСТАНОВКИ">
    «мені вдалося» пасує → was able to · «мабуть» пасує → must be · «не смій» пасує → mustn’t · «як хочеш» пасує → don’t have to
  </CheatRow>
  <CheatRow label="РЕГІСТР">
    Наказ Send me the file у листі — різко. Мінімум: Could you send…? · Порада без тиску: You might want to…<br />
    might — «можливо» за замовчуванням; вічне Maybe he is… — акцент перекладу
  </CheatRow>
</Cheat>
