<Note variant="tip" title="Та сама схема словами — для повторення в черзі">
  <b>1.</b> Оцінюєте шанси («мабуть», «можливо», «точно ні»)? → шкала впевненості: must be / might be / can’t be.<br />
  <b>2.</b> Просите? → драбина ввічливості: Can I → Could I → May I; Can you → Could you → Would you mind.<br />
  <b>3.</b> Тиснете? → шкала тиску: should (варто) → have to / must (мусиш) → mustn’t / can’t (не можна). «Не обовʼязково» — don’t have to.<br />
  <b>4.</b> Нічого з цього → уміння чи воля: can / could / will / won’t.
</Note>
