<Note variant="tip" title="Та сама схема словами — для повторення в черзі">
  <b>1.</b> Уже стоїть my / this / some / число? → нічого не треба.<br />
  <b>2.</b> Власна назва? → зазвичай без артикля (винятки — <SecRef n={7} />).<br />
  <b>3.</b> Співрозмовник знає, який саме? → <b>the</b>.<br />
  <b>4.</b> Не знає. Можна порахувати, і воно одне? → <b>a/an</b> (за звуком). Множина чи розмазня? → <b>нічого</b> або some.
</Note>
