# Граматика англійської

Особистий навчальний сайт: правила англійської граматики з поясненнями українською,
прикладами з перекладом, вправами і тестами.

Статичний сайт — без збірки, без залежностей, без Node. Просто HTML, CSS і трохи JS.
Відкривається подвійним кліком по `index.html`.

---

## Структура

```
english-grammar/
├── index.html              головна: список тем (картки малюються з topics.js)
├── _template.html          шаблон нової теми — копіюйте його
├── README.md               цей файл
├── assets/
│   ├── css/main.css        ВСІ стилі сайту, спільні для всіх сторінок
│   └── js/
│       ├── main.js         прогрес-бар, кнопки «Відповідь», рушій тесту
│       └── topics.js       СПИСОК ТЕМ — єдиний файл для правок при додаванні теми
└── topics/
    └── past-tenses.html    Past Simple · Past Continuous · Past Perfect
```

---

## Як додати нову тему

1. Скопіюйте `_template.html` у `topics/` під новим імʼям латиницею:

   ```bash
   cp _template.html topics/articles.html
   ```

2. Відредагуйте: `<title>`, `<meta description>`, шапку, розділи.
   У шаблоні вже є всі готові «цеглинки» з коментарями — формула, список прикладів,
   правильно/неправильно, виноска, таблиця, вправа, мінімальні пари, тест.

3. Додайте картку теми в `assets/js/topics.js`:

   ```js
   {
     title: 'Артиклі: a / an / the',
     desc: 'Коротко про що тема.',
     href: 'topics/articles.html',
     level: 'a2',                       // a2 | b1 | b2 | c1 — колір смужки
     tags: ['10 розділів', 'тест'],
     ready: true
   }
   ```

4. Відкрийте `index.html` — картка вже там.

CSS і JS чіпати не треба: нова сторінка підхоплює їх автоматично.

## Готові CSS-класи

| Клас | Що це |
|---|---|
| `.formula` | темний блок з формулою часу/конструкції |
| `.exlist` > `.row` > `.en` / `.ua` / `.why` | список прикладів: англійська, переклад, пояснення |
| `.gb` > `.bad` / `.good` | пара «неправильно / правильно» |
| `.note`, `.note warn`, `.note trap`, `.note tip` | виноски: нейтральна, увага, пастка, порада |
| `.mp` > `.mp-h` / `.mp-r` | мінімальні пари |
| `.drill` + `.reveal` + `.answer` | вправа з кнопкою «Відповідь» |
| `.revealall` + `data-target="id"` | кнопка «показати всі відповіді» в блоці |
| `.chips` > `.chip`, `.chip ps/pc/pp` | теги слів-маркерів |
| `.card`, `.grid2`, `.grid3` | картки і сітки |
| `.svgbox` + `.caption` | контейнер для схеми/таймлайна |
| `mark.m-ps` / `.m-pc` / `.m-pp` | кольорове підсвічування дієслова в прикладі |

Кольорова система: синій = Past Simple, помаранчевий = Continuous, фіолетовий = Perfect.
Для інших тем кольори можна перевикористати як «варіант 1 / 2 / 3».

## Як опублікувати

Сайт статичний, тому підійде будь-який безкоштовний хостинг.

### GitHub Pages

```bash
cd /Volumes/Work/english-grammar
git init
git add .
git commit -m "Перша тема: минулі часи"
git branch -M main
git remote add origin https://github.com/<ваш-нік>/english-grammar.git
git push -u origin main
```

Далі в репозиторії: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
Через хвилину сайт буде на `https://<ваш-нік>.github.io/english-grammar/`.

Файл `.nojekyll` уже є — він потрібен, щоб GitHub не обробляв сайт як Jekyll-блог.

### Netlify або Cloudflare Pages

Перетягніть папку у веб-інтерфейс — і все. Збірка не потрібна,
build command порожній, publish directory — коренева папка.
